# Trying to Build Well

A well-structured TypeScript project demonstrating best practices for building software.

## What Can You Build Very Well?

This project demonstrates how to build software very well by following best practices:

1. **Type Safety** - Using TypeScript for compile-time type checking
2. **Testing** - Comprehensive unit tests with Jest
3. **Code Quality** - ESLint for linting and Prettier for formatting
4. **Build System** - TypeScript compiler with proper configuration
5. **Documentation** - Clear JSDoc comments and README
6. **Project Structure** - Clean separation of concerns

## Features

- ✅ TypeScript for type safety
- ✅ Jest for testing
- ✅ ESLint for code quality
- ✅ Prettier for code formatting
- ✅ Comprehensive build scripts
- ✅ Well-documented code

## Installation

```bash
npm install
```

## Building

Build the project:

```bash
npm run build
```

Clean build artifacts:

```bash
npm run clean
```

## Running

After building, run the application:

```bash
npm start
```

## Testing

Run all tests:

```bash
npm test
```

## Code Quality

Lint the code:

```bash
npm run lint
```

Format the code:

```bash
npm run format
```

## Project Structure

```
.
├── src/                    # Source files
│   ├── calculator.ts       # Calculator utility class
│   ├── calculator.test.ts  # Calculator tests
│   └── index.ts           # Application entry point
├── dist/                   # Compiled output (generated)
├── .eslintrc.json         # ESLint configuration
├── .prettierrc.json       # Prettier configuration
├── jest.config.js         # Jest configuration
├── tsconfig.json          # TypeScript configuration
└── package.json           # Project dependencies and scripts
```
