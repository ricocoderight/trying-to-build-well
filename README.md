# trying-to-build-well

A simple Python calculator project for testing and demonstration purposes.

## Features

- Basic arithmetic operations (add, subtract, multiply, divide)
- Comprehensive unit tests
- Simple and clean code structure

## Running the Application

```bash
python3 calculator.py
```

## Running Tests

```bash
python3 -m unittest test_calculator.py -v
```

## Project Structure

- `calculator.py` - Main calculator module with arithmetic functions
- `test_calculator.py` - Unit tests for the calculator
- `requirements.txt` - Project dependencies (none required for this simple project)

## Requirements

- Python 3.x (no external dependencies required)
